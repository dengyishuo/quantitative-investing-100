# 第075讲 VaR与CVaR：用数字告诉你，极端情况会亏多少

> 所属模块：模块07｜风控·活着才有输出  
> 建议时长：10–12 分钟  
> 内容状态：已完成（课程版 v1.0）

> 风险提示：本文仅用于量化投资知识教育，不构成任何投资建议。风控指标与阈值需结合资产、流动性和个人承受能力验证。

## 本讲目标

- 理解 VaR 分位损失与 CVaR 尾部均值。
- 掌握历史、参数和模拟三种估计。
- 识别模型与流动性局限。

## VaR 回答什么

给定持有期与置信水平，VaR 表示损失分布的某个分位阈值。例如 95% 一日 VaR 并不意味着最大损失，只表示模型下约 5% 情形会更差。

## CVaR

CVaR（Expected Shortfall）是超过 VaR 后的平均损失，更关注尾部严重程度。两个组合 VaR 相同，CVaR 可能完全不同。

## 三种方法

- **历史模拟**：直接用历史收益，保留非正态，但受样本限制。
- **参数法**：假设分布并用均值协方差估计，快速但可能低估厚尾。
- **蒙特卡洛**：模拟风险因子路径，灵活但依赖模型。

## 口径

必须说明置信度、持有期、头寸是否动态、估值模型和数据窗口。不能随意用平方根时间把一日 VaR 扩展到长期。

## 局限

历史外事件、流动性冲击、非线性期权和相关性突变都可能使 VaR 失真。它应与压力测试、限额和情景分析一起使用。

## 风险预案：触发之后具体做什么

围绕“VaR与CVaR：用数字告诉你，极端情况会亏多少”写一份可执行的风险预案。风险指标只有绑定阈值、权限、动作和恢复条件，才能从报告上的数字变成真正的控制。

1. 定义风险对象、计算窗口、更新频率、阈值和数据依赖。
2. 设置预警、降仓、停止开仓和紧急平仓等分级动作，并明确授权人。
3. 加入相关性上升、流动性消失、价格跳空和模型失效等非历史常态情景。
4. 规定事件记录、复盘、重新启用条件与人工覆盖流程。

## 常见误区与修正

- 把历史波动率当成全部风险；尾部、流动性和操作风险需要单独处理。
- 只有止损阈值，没有成交与恢复方案；极端市场里订单可能无法按预期成交。
- 风险规则频繁临时修改；任何人工覆盖都应授权、留痕并事后复盘。

## 实战验收清单

- [ ] 指标、阈值、动作和负责人一一对应
- [ ] 至少覆盖一个历史未充分出现的压力情景
- [ ] 组合级风险与单资产风险均有限额
- [ ] 暂停、恢复和人工覆盖流程可审计

## 本讲小结

- VaR 是分位阈值，不是最大亏损。
- CVaR 描述越过阈值后的平均尾部损失。
- 方法选择与假设必须透明，并由压力测试补充。

## 课后练习

用 100 个日收益计算 95% 历史 VaR 与 CVaR，比较最坏 5 个样本。
