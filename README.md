# 量化投资100讲

《量化投资100讲》是一套面向量化投资学习者的公开课程，覆盖量化世界观、数学基础、金融数据、经典策略、因子投资、回测、风险管理、资产配置、机器学习与实战工程。

全书目前共 11 个模块、106 讲。课程强调把投资想法转化为有证据、可复现、可执行、可监控、也可被证伪的决策系统。

## 风险提示

本项目仅用于量化投资知识教育，不构成任何投资建议。历史规律、回测结果和模型输出均不保证未来表现。使用任何策略前，应独立核查数据、交易成本、容量、风险暴露和适用边界。
