# 第054讲 什么是因子？Beta与Alpha的前世今生

> 所属模块：模块05｜因子投资·寻找Alpha  
> 建议时长：10–12 分钟  
> 内容状态：已完成（课程版 v1.0）

> 风险提示：本文仅用于量化投资知识教育，不构成任何投资建议。因子历史表现不代表未来收益。

## 本讲目标

- 理解因子是可重复的收益与风险解释维度。
- 区分 Beta 暴露与 Alpha。
- 建立因子研究的定义、检验和实现流程。

## 因子是什么

因子是能在大量资产上统一计算、用于解释收益差异或预测相对表现的特征。市值、估值、动量、质量和波动都可构成因子，但一个财务字段不自动等于有效因子。

## Beta 与 Alpha

Beta 表示组合对系统性风险来源的敏感度；Alpha 是在给定风险模型下未被解释的剩余收益。Alpha 不是永久标签：风险模型加入新因子后，过去的 Alpha 可能变成某种 Beta。

## 因子收益链

> 原始字段 → 清洗 → 行业与规模处理 → 标准化 → 排序或回归 → 组合 → 成本后收益

每一步都会影响结论。因子必须按当时可得数据计算，并说明方向、更新频率和缺失处理。

## 为什么因子可能存在

可能来自承担风险、行为偏差、制度约束或交易摩擦。经济解释帮助判断持续性，但不能代替样本外证据。

## 检验维度

观察分组单调性、Rank IC、换手率、因子收益、跨市场稳定性、与已知因子相关性及成本后容量。一次显著回归不够。

## 因子研究卡：定义、检验与组合

研究“什么是因子？Beta与Alpha的前世今生”时，先把经济直觉、因子定义与组合实现分开。下面的流程可防止一个看似漂亮的排序结果被行业、规模或数据口径误导。

1. 明确因子值、方向、截面范围、调仓频率和未来收益窗口。
2. 按决策时点对齐数据，处理极值、缺失，并说明标准化与中性化方法。
3. 同时查看 IC、Rank IC、分组单调性、换手率、成本后收益和不同市场阶段。
4. 将因子加入已有组合，检查边际贡献、相关性、风险暴露与容量，而不是只看单因子回测。

## 常见误区与修正

- 因子定义随结果不断调整；应先冻结定义，再保留真正独立的样本外区间。
- 忽略行业、规模或风格暴露；超额收益可能只是已知风险因子的替身。
- 只看多空组合收益；实际多头组合还受基准、约束、换手和可交易性影响。

## 实战验收清单

- [ ] 因子方向、频率和未来收益窗口无歧义
- [ ] 数据按当时可得口径对齐
- [ ] 单调性、稳定性、换手和成本均已报告
- [ ] 与已有因子及风险暴露完成增量比较

## 本讲小结

- 因子是跨资产可统一计算的解释或预测特征。
- Alpha 取决于所采用的风险模型。
- 从字段到可交易收益需经过完整的数据与组合链路。

## 课后练习

选择一个因子，写出定义卡：经济逻辑、字段、时间、清洗、方向、频率、评价和失效条件。
