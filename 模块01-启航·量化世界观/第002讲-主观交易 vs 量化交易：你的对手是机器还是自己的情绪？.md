# 第002讲 主观交易 vs 量化交易：你的对手是机器还是自己的情绪？

> 所属模块：模块01｜启航·量化世界观  
> 建议时长：10–12 分钟  
> 内容状态：已完成（课程版 v1.0）

> 风险提示：本文仅用于量化投资知识教育，不构成任何投资建议。任何交易方法都可能亏损，系统化规则也无法消除市场风险。

## 本讲目标

学完本讲，你应该能够：

- 准确区分主观交易与量化交易，而不是简单判断谁更高级。
- 理解两种方法各自的信息优势、适用场景和典型失误。
- 识别交易中最常见的情绪与认知偏差。
- 把一个依赖“盘感”的判断，改写成可记录、可测试的决策流程。

## 0–1 分钟：同一张图，为什么你每天都能得出不同结论？

假设一只股票连续上涨五天，今天突然放量下跌。

你可以给出至少四种解释：

- 上涨趋势结束，应该立即卖出。
- 主力洗盘，是更好的买点。
- 市场出现利空，需要等待信息确认。
- 正常波动，不应该频繁操作。

这些解释都可能听起来合理。真正的问题是：如果明天价格反弹，你会不会重新解释一次？如果账户正在盈利或亏损，你的判断标准会不会改变？

主观交易与量化交易的差异，不只是“人脑对电脑”，而是：

> 决策标准是在行情发生前定义，还是在行情发生后解释。

## 1–3 分钟：两种交易方式分别是什么？

### 主观交易

主观交易也叫自主决策交易或酌情交易。交易者综合价格走势、公司信息、政策变化、行业经验和市场氛围，在当下做出判断。规则可以存在，但人保留最终解释权和否决权。

一个典型决策可能是：

> 公司基本面不错，最近调整充分，市场情绪开始回暖，我认为可以分批买入。

这句话可能包含大量经验，但“不错”“充分”“回暖”并没有被严格定义，不同时间、不同交易者可能给出不同结论。

### 量化交易

量化交易事先定义数据、信号、仓位、执行和退出规则，再由计算工具持续应用。人主要在系统设计、数据治理、风险边界和模型监控环节做判断。

同一个想法可以改写为：

> 资产满足盈利质量和流动性条件；过去 20 个交易日跌幅处于历史低分位；短期成交量恢复且价格重新站上预设均线；次日按目标风险仓位执行。

量化表达未必更正确，但它更容易复现、检验和反驳。

## 3–5 分钟：两种方法的核心差异

| 比较维度 | 主观交易 | 量化交易 |
|---|---|---|
| 信息处理 | 擅长新闻、访谈、政策语境等非结构化信息 | 擅长大规模、标准化、可计算的数据 |
| 决策方式 | 人在当下综合判断 | 事先定义规则，按系统输出决策 |
| 覆盖范围 | 通常深度研究少量资产 | 可以同时扫描大量资产与信号 |
| 执行一致性 | 容易受状态、压力和叙事影响 | 相同输入通常产生相同输出 |
| 反应能力 | 对突发事件和制度变化更灵活 | 对规则内事件反应快，规则外事件可能迟钝 |
| 可检验性 | 经验难完整还原，容易事后合理化 | 可以回测、复盘和做样本外检验 |
| 主要优势 | 语境理解、因果判断、处理罕见情形 | 纪律、规模、速度、可复现性 |
| 典型风险 | 情绪化、标准漂移、选择性记忆 | 数据偏差、过拟合、模型失效、拥挤交易 |

因此，两者不是“落后方法”和“先进方法”的关系。它们是在不同信息环境中，用不同方式组织决策。

主观交易更像经验丰富的医生面对复杂病例：能够结合语境处理例外。量化交易更像标准化检验系统：可以稳定处理大量样本，但只认识被定义过的数据和规则。

## 5–7 分钟：你的真正对手，为什么常常是自己的情绪？

机器不会因为连续亏损三次就急于翻本，也不会因为刚赚了一笔就擅自放大仓位。人却很容易在压力下改变标准。

### 1. 损失厌恶

同等金额的亏损，带来的痛苦通常大于盈利带来的快乐。结果是：亏损仓位不愿卖，希望“回本再走”；盈利仓位却过早落袋为安。

### 2. 近期偏差

人会把最近发生的事情看得过重。策略刚连续盈利，就相信它永远有效；刚经历几次亏损，就认为逻辑已经彻底失效。

### 3. 确认偏差

持仓以后，我们更愿意阅读支持自己观点的信息，并下意识忽略反面证据。研究逐渐从“寻找真相”变成“证明自己没错”。

### 4. 锚定效应

买入价、历史高点或某位专家给出的目标价，很容易成为心理锚。市场环境已经变化，决策却仍围绕那个数字展开。

### 5. 行动偏差

面对不确定性，人容易觉得“必须做点什么”。频繁调仓带来掌控感，却可能只增加交易成本和犯错次数。

### 6. 事后聪明

行情走完以后，所有拐点看起来都很明显。人会高估自己当时真正掌握的信息，低估市场原本存在的多种可能。

量化规则的价值之一，就是在情绪出现之前先写下决策边界。但要注意：如果交易者每次亏损后都临时修改参数，量化系统同样会退化成“用代码包装的情绪交易”。

## 7–9 分钟：主观与量化，谁更适合什么场景？

### 主观方法更有优势的场景

- 政策突然改变，历史数据尚未覆盖新制度。
- 公司治理、管理层可信度等信息难以完整结构化。
- 市场出现极端事件，需要判断历史关系是否仍然成立。
- 研究对象很少，但单个对象需要深度理解。

### 量化方法更有优势的场景

- 需要同时比较数百或数千个资产。
- 规则需要高频、长期且不间断地执行。
- 策略依赖多个数据条件，人工容易漏看或算错。
- 需要严格控制仓位、交易成本和组合风险暴露。
- 需要检验某个经验到底是规律，还是少数成功案例造成的错觉。

### 更现实的答案：人机分工

成熟的投资流程常常不是二选一，而是把不同任务交给更适合的一方。

人可以负责：

- 提出投资假设和经济解释。
- 判断市场制度是否发生结构性变化。
- 设定风险预算和不可突破的边界。
- 审查数据、模型和异常事件。

机器可以负责：

- 统一计算指标并扫描大量资产。
- 按固定标准生成候选与仓位。
- 执行订单、记录日志和监控偏离。
- 对历史结果做重复、客观的统计检验。

最理想的状态不是让机器替代人，而是：

> 让人负责定义问题、处理例外和承担责任，让机器负责重复计算、纪律执行和完整记录。

## 9–10 分钟：把“盘感”变成可以复盘的流程

假设你的原始判断是：

> 这只股票跌得差不多了，成交量也起来了，可以抄底。

可以分四步改写。

### 第一步：拆出模糊词

- “跌得差不多”到底是跌了多少？
- 相对什么时间窗口计算？
- “成交量起来”是高于昨天，还是高于过去均值？
- “抄底”后持有多久？判断错误如何退出？

### 第二步：写成观察条件

例如，仅作为教学示意：

- 过去 20 个交易日跌幅低于某个历史分位。
- 当日成交量高于过去 20 日均量的预设倍数。
- 收盘价重新回到短期均线之上。

### 第三步：补齐交易与风险规则

- 信号在收盘后计算，下一交易日执行。
- 单一资产仓位不得超过组合上限。
- 设定退出、最长持有时间和组合回撤处置规则。
- 回测时计入手续费、滑点、涨跌停和无法成交的情况。

### 第四步：记录反例

不要只记录成功抄底的案例。所有满足条件的样本都应进入统计，包括失败、长时间横盘和继续下跌的情况。

经过这四步，一个主观经验才真正变成可以讨论、测试和迭代的策略假设。

## 选择方法的四个问题

开始交易前，可以先问自己：

1. 我的优势来自深度理解少数对象，还是稳定扫描大量对象？
2. 决策所需信息能否被及时、可靠地结构化？
3. 我是否能够真实记录每次交易前的理由，而不是事后补充解释？
4. 当规则连续亏损时，我有统计标准判断“正常回撤”与“模型失效”吗？

如果你擅长行业研究，却强迫自己只看价格信号，可能会丢掉优势；如果你没有时间持续盯盘，却依赖临场感觉，也很难保持一致。方法要与信息优势、时间条件和心理承受能力匹配。

## 认知落地：把概念变成决策

这一讲不是让你记住一个口号，而是训练你在真实投资问题里识别它。围绕“主观交易 vs 量化交易：你的对手是机器还是自己的情绪？”，可以用下面的四步把抽象概念落地。

1. 写清决策对象：谁在什么时间、基于哪些已知信息做什么决定。
2. 区分模型、信号、订单与持仓，避免把一个判断直接当成完整策略。
3. 列出可观察证据与反例：什么现象支持这个判断，什么现象会推翻它。
4. 补上数据、执行和风险约束，再判断它是否具备系统化与可复现性。

## 常见误区与修正

- 只记定义，不说明决策时点和输入信息；修正方法是把概念改写成一条可执行规则。
- 用一次成功案例证明方法有效；修正方法是同时寻找失败样本和适用边界。
- 把技术复杂度当成投资优势；真正需要验证的是信息、行为或结构性机制。

## 本讲小结

- 主观交易由人综合语境做最终判断；量化交易把数据和决策标准事先系统化。
- 主观方法擅长理解非结构化信息和处理例外，量化方法擅长规模化计算、纪律执行和客观检验。
- 交易者常见的对手包括损失厌恶、近期偏差、确认偏差、锚定效应和行动偏差。
- 写了代码不代表摆脱情绪；亏损后随意改参数，同样属于标准漂移。
- 更有效的实践通常是人机分工：人提出假设和管理边界，机器执行、记录与监控。

## 课后练习：给自己的交易做一次“规则体检”

找出最近一次真实或模拟的买卖决策，完成下面的表格：

| 问题 | 交易前真实答案 |
|---|---|
| 我为什么买入？ |  |
| 哪些数据支持这个判断？ |  |
| 什么证据会证明我错了？ |  |
| 买入多少，依据是什么？ |  |
| 计划何时退出？ |  |
| 结果不理想时，我是否临时改变过标准？ |  |

然后把理由中的“感觉不错”“跌得够多”“应该会涨”等模糊词圈出来，至少选择一个改写成可观察、可计算的条件。
