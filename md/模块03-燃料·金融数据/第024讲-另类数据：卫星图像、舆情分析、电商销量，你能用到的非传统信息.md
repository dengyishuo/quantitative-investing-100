# 第024讲 另类数据：卫星图像、舆情分析、电商销量，你能用到的非传统信息

> 风险提示：本文仅用于量化投资知识教育，不构成任何投资建议。数据示例与方法需结合真实市场规则验证。

## 本讲目标

- 理解另类数据的价值链与成本。
- 区分数据新颖性和可交易增量。
- 识别隐私、授权和时间戳风险。

## 什么是另类数据

相对传统行情与财报，卫星图像、招聘信息、网页访问、应用活跃、物流、电商销量、文本舆情和链上活动等常被称为另类数据。它们可能更及时或更细颗粒，但通常更脏、更贵、更难解释。

## 从原始数据到信号的五步

1. 获取合法授权且持续可用的数据。
2. 将图片、文本或事件转成结构化特征。
3. 对齐实体，例如把门店、品牌映射到上市公司。
4. 确认数据产生、发布和可获取时间。
5. 检验其在传统因子之外是否有增量。

任何一步失败，都可能把“新数据”变成昂贵噪声。

## 舆情例子

情绪模型输出正负分数不等于交易信号。需要处理转发重复、机器人账号、语言反讽、公司别名和新闻发生时间。更重要的是判断市场是否已经定价。

## 三类风险

- **选择偏差**：供应商只展示成功案例或历史覆盖不断变化。
- **数据漂移**：平台规则、用户结构和采样方式变化。
- **合规风险**：隐私、版权、用户授权和跨境使用边界不清。

## 评估框架

比较加入数据前后的样本外表现、换手率、容量和稳定性，并计算数据成本与工程维护成本。另类数据的价值不在“另类”，而在是否带来持续、合法、可执行的增量信息。

## 一条“及时信息”是怎样失去及时性的

假设研究者使用招聘信息判断企业扩张。职位发布发生在某日，但爬虫可能数日后才抓到；平台会修改或删除页面，供应商还可能在月底统一回补历史数据。若回测使用回补后的完整职位列表，并把所有记录放回最初发布日期，就假设系统当时已经看到了后来才收集的数据。

因此另类数据至少需要三个时间：原始事件发生时间、供应商首次观测时间、策略完成处理后的可用时间。最早时间不一定是最真实的决策时间。

## 实体映射往往比模型更难

电商品牌、门店、应用名称和上市公司代码之间不是简单一一对应。一个品牌可能属于集团子公司，一家上市公司也可能经营多个品牌；并购、改名和地区授权又会改变映射。若今天的集团关系回填到过去，就可能产生后见偏差。

实体映射表应带生效区间、来源和置信度。无法确定归属的数据宁可单独保留，也不要为了提高覆盖率强行匹配。错误映射会产生看似精确、实则不可解释的信号。

## 新数据是否真的提供增量

另类数据经常只是传统信息的昂贵代理。例如招聘增加可能与已经公开的收入增长、行业景气或股价动量高度相关。检验时先建立只使用传统因子的基线，再加入另类特征，比较样本外增量、稳定性、换手和成本。

如果提升只存在于特定供应商回溯样本，或扣除数据采购与工程维护后不再有经济价值，新颖性就没有转化为投资能力。

## 合规应进入特征生命周期

数据合法取得并不自动意味着可以无限期、跨用途使用。研究前要记录授权范围、个人信息处理、保存期限、跨境限制和删除机制；供应商变更条款时，还要知道哪些模型和历史结果受到影响。

另类数据的停用标准也应提前定义：覆盖率骤降、采样机制变化、实体映射失效、授权不再明确，或样本外增量持续消失。数据源失效时，策略不能继续把旧特征当作同一种信息。

## 数据审计：先证明当时真的看得到

围绕“另类数据：卫星图像、舆情分析、电商销量，你能用到的非传统信息”建立一张数据审计卡。目标不是把表填满，而是证明每个字段在决策时点真实可得、口径一致并可追溯。

1. 记录字段定义、来源、原始频率、发布时间、修订规则与授权范围。
2. 区分事件发生时间、数据发布时间、采集时间和策略可用时间。
3. 统计缺失、重复、异常和覆盖率，并保留原始值与清洗日志。
4. 用小样本从原始数据重建一个指标，核对复权、单位和时间对齐。

## 证据、边界与风险

- **参考资料**：
  - [pandas 官方用户指南](https://pandas.pydata.org/docs/user_guide/index.html)：时间序列、缺失值与数据变换。
  - [scikit-learn：Common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html)：数据泄漏与训练、测试隔离。
- **适用条件与边界**：数据许可、交易日历、公司行动和披露时点因市场而异；今天修订后的数据库不等于历史当时可见信息。
- **主要失败模式**：使用后见修订数据、幸存股票池或错误复权，并把缺失值静默填充成不存在的事实。

## 常见误区与修正

- 用今天看到的历史数据假装当时已经可得；应使用 point-in-time 快照或发布时间约束。
- 直接删除缺失值而不解释缺失机制；缺失本身可能包含选择偏差。
- 只保存清洗后结果；没有原始快照和日志就无法复现与审计。

## 实战验收清单

- [ ] 每个核心字段有来源和更新时间
- [ ] 不存在使用未来修订值的前视偏差
- [ ] 缺失、异常、重复与退市样本均有处理记录
- [ ] 从原始数据到研究表的变换可以重放

## 本讲小结

- 另类数据需要经过获取、结构化、实体映射、时间对齐和增量检验。
- 新颖不等于有效，工程与合规成本可能超过收益。
- 数据漂移和授权边界必须持续监控。
